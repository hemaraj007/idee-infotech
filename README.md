# Idee Infotech

Website for Idee Infotech, a digital marketing company (SEO, social media, paid ads, content, branding and websites).

Single-file static site: `index.html` (HTML, CSS and JS inline, logo embedded).

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
Settings > Pages > Deploy from a branch > `main` / root.
